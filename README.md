# Documentación Técnica Bizner GCP PRD

Portal oficial de arquitectura, inventario de servicios, infraestructura y manual de operaciones del ecosistema de producción Bizner en Google Cloud Platform.

## Despliegue en GitHub Pages

Este sitio se compila mediante [Docusaurus](https://docusaurus.io/) y se despliega automáticamente en GitHub Pages mediante GitHub Actions al hacer `push` a la rama `main`.

URL de producción: [https://noreplybizner.github.io/Documentacion_bizner/](https://noreplybizner.github.io/Documentacion_bizner/)

## Comandos Principales

```bash
# Instalar dependencias
npm install

# Iniciar servidor local de desarrollo
npm start

# Compilar para producción
npm run build

# Previsualizar la compilación localmente
npm run serve
```
